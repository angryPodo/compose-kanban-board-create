## 🚀 2단계 - 칸반 보드 생성(보드)

안드로이드 8기 레벨 1 미션, 칸반 보드 생성 미션을 관리하는 프로젝트입니다.

## 2단계 기능 및 작업 명세

### 칸반 보드 헤더 UI 구현
- 보드 상단에 애플리케이션 이름과 전체 태스크의 개수, 완료된 태스크의 개수를 제공합니다.
- 전체 태스크 대비 완료된 태스크의 비율을 계산하여 백분율로 제공합니다.
- 계산된 백분율과 대응되는 진행도 UI를 제공합니다.
- 상단의 "새 태스크 생성" 버튼을 클릭하여 태스크 생성 다이얼로그를 노출시킵니다.

### 칸반 보드 메인 UI 구현
- 상태(To-Do, In Progress, Done)별로 컬럼을 나누어 태스크 목록을 제공합니다.
- 각 상태별 칸반 컬럼 상단에 해당 상태에 속한 태스크 개수를 표시합니다.
- 상태별로 태스크 개수가 많아질 경우, 화면 영역을 벗어나지 않고 컬럼 내부에서 세로 스크롤이 가능하도록 구현합니다.

### 태스크 생성 완료 스낵바 구현
- 태스크가 성공적으로 생성되었을 때 화면 하단에 스낵바를 제공하여 사용자에게 피드백을 전달합니다.
- 스낵바의 X 아이콘을 누르거나, 시간이 지나면 자동으로 사라지도록 처리합니다.
- 태스크 생성 다이얼로그에서 유효하지 않은 입력으로 인해 생성이 불가능한 경우에는 스낵바를 노출하지 않습니다.

## 테스트 명세

### 단위 테스트
- **보드 상태 및 통계 검증**
  - 빈 보드 상태일 때 진행률이 0%로 계산되는지 확인합니다.
  - 태스크 상태(To-Do, In Progress, Done)에 따라 태스크가 올바르게 분류되는지 확인합니다.
  - 완료된 태스크 수와 전체 태스크 수에 따른 진행률 계산 로직을 검증합니다.
  - 새로운 태스크가 추가될 때 보드의 전체 상태가 올바르게 갱신되는지 확인합니다.
- **UI 상태 관리 및 비즈니스 로직 검증**
  - 다이얼로그의 노출/숨김 상태 전환이 올바른지 확인합니다.
  - 태스크 추가 시 도메인 모델로의 변환 및 데이터 업데이트 로직을 검증합니다.
  - 태스크 생성 성공 시의 시나리오를 상태 레벨에서 검증합니다.

### Compose UI 테스트
- **컴포넌트 노출 및 상호작용 검증**
  - "새 태스크 생성" 버튼 클릭 시 다이얼로그가 정상적으로 표시되는지 확인합니다.
  - 주입된 보드 상태(태스크 목록, 완료율 등)가 화면에 올바른 텍스트 포맷으로 렌더링되는지 확인합니다.
  - 각 상태 컬럼과 태스크 카드가 의도한 위치에 노출되는지 확인합니다.
